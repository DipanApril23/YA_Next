# ─────────────────────────────────────────────────────────────────────────────
# robots.txt — youngarchitects.in
#
# POLICY: the whole site is open to every well-behaved crawler, search engine
# and AI assistant alike. Nothing here is private. The build is a fully static
# export (next.config.mjs → output: "export"), so there are no API routes, no
# admin panels and no server endpoints that could need keeping out of an index.
#
# NOTHING IS BLOCKED, AND THAT IS DELIBERATE — DO NOT "TIDY" THIS UP.
# Most pages on this site are Coming Soon placeholders that ship
# <meta name="robots" content="noindex, follow"> from
# src/app/(site)/[...slug]/page.jsx. A crawler has to FETCH a page to read that
# tag. Disallowing those paths here would hide the noindex, and a blocked URL
# can still be indexed from inbound links — with no description, because the
# crawler was never allowed to look. Blocking would achieve the exact opposite
# of what it looks like it achieves. Leave them crawlable.
#
# /_next/ MUST STAY CRAWLABLE TOO. It holds the CSS and JS the page needs to
# render. Google renders before it ranks; block this and the site looks broken
# to the renderer even though it looks fine to you.
#
# WHY THE AI AGENTS ARE LISTED INDIVIDUALLY BELOW when "User-agent: *" already
# allows them: robots.txt groups are not additive. A crawler obeys the single
# most specific group that names it and ignores every other group, "*"
# included. Naming them means that the day someone adds a Disallow to the "*"
# group, the assistants below keep their current access instead of silently
# inheriting the new restriction. The list is documentation of intent as much
# as configuration.
# ─────────────────────────────────────────────────────────────────────────────

# ── Google — Gemini and AI Overviews ─────────────────────────────────────────
# Google-Extended is NOT a crawler. It is a permission switch: it governs
# whether content already fetched by Googlebot may ground Gemini and train
# Google's models. It has no effect on Google Search ranking, and AI Overviews
# are served from the ordinary Googlebot index either way. Allowed here so the
# opt-in is on the record.
User-agent: Googlebot
User-agent: Google-Extended
User-agent: GoogleOther
Allow: /
